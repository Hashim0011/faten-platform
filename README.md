# منصة فطن 🧠

منصة تعليمية متكاملة متخصصة في الأمن الفكري، تجمع بين المحتوى التعليمي عالي الجودة والنقاشات التفاعلية مع الخبراء المتخصصين.

## 📋 نظرة عامة

**فطن** هي منصة تعليمية عربية تهدف إلى تعزيز الأمن الفكري من خلال:
- توفير محتوى تعليمي موثوق (كتب، فيديوهات، مقالات)
- تسهيل التواصل مع خبراء متخصصين
- إنشاء مجتمع تفاعلي للنقاشات الهادفة
- تتبع التقدم والإنجازات التعليمية
- مساعد ذكاء اصطناعي للإجابة على الأسئلة

## ✨ المميزات الرئيسية

### للمستخدمين 👥
- **مكتبة محتوى شاملة**: الوصول إلى مئات الكتب والفيديوهات والمقالات المتخصصة
- **نقاشات تفاعلية**: المشاركة في نقاشات مع خبراء في الأمن الفكري
- **مساعد AI ذكي**: الحصول على إجابات فورية من الذكاء الاصطناعي
- **تتبع التقدم**: مراقبة الإنجازات والساعات المنجزة
- **نظام الإشعارات**: تنبيهات فورية بالمحتوى والنقاشات الجديدة
- **واجهة عربية بالكامل**: تجربة مستخدم سلسة بتصميم عصري

### للخبراء 🎓
- **لوحة تحكم متخصصة**: إدارة النقاشات والمستخدمين
- **جدولة النقاشات**: تنظيم الجلسات والمواعيد
- **تقييمات ومراجعات**: الحصول على تقييمات من المستخدمين
- **إحصائيات مفصلة**: متابعة الأداء والتفاعل
- **إدارة المحتوى**: إضافة وتعديل وحذف المحتوى التعليمي

### للإداريين 🛡️
- **لوحة إدارة شاملة**: التحكم الكامل في المنصة
- **إدارة المحتوى**: إضافة وتعديل وحذف المحتوى التعليمي
- **إدارة المستخدمين والخبراء**: مراقبة وإدارة الحسابات (تعليق/حذف/تفعيل)
- **تقارير وتحليلات**: إحصائيات مفصلة عن أداء المنصة
- **نظام الإشعارات**: متابعة التقارير والأحداث المهمة

## 🛠️ التثبيت والإعداد

### المتطلبات الأساسية
- **Node.js** (الإصدار 16 أو أحدث)
- **npm** أو **yarn** أو **pnpm**
- متصفح حديث (Chrome, Firefox, Safari, Edge)

### خطوات التثبيت

1. **استنساخ المشروع**
```bash
git clone <repository-url>
cd Faten
```

2. **تثبيت الحزم**
```bash
npm install
```

3. **تشغيل بيئة التطوير**
```bash
npm run dev
```

4. **فتح المتصفح**
```
افتح http://localhost:5173 (أو المنفذ المتاح التالي)
```

## 👥 أنواع المستخدمين

### 1. المستخدم العادي (User)
- تصفح المحتوى التعليمي (كتب، فيديوهات، مقالات)
- حجز النقاشات مع الخبراء
- استخدام مساعد AI للأسئلة
- تتبع التقدم الشخصي
- المشاركة في المجتمع
- استقبال الإشعارات

### 2. الخبير (Expert)
- إدارة النقاشات المجدولة
- الرد على استفسارات المستخدمين
- تتبع الأداء والتقييمات
- إدارة الجدول الزمني
- إدارة المحتوى (إضافة/تعديل/حذف)
- متابعة المستخدمين النشطين
- استقبال إشعارات النقاشات

### 3. المدير (Admin)
- إدارة المحتوى (إضافة/تعديل/حذف)
- إدارة المستخدمين (تعليق/حذف/تفعيل)
- إدارة الخبراء ومراقبة أدائهم
- مراقبة نشاط المنصة بالكامل
- عرض التقارير والإحصائيات المفصلة
- استقبال تنبيهات إدارية

## 🎨 التصميم والألوان

### لوحة الألوان الرئيسية
```css
:root {
  --primary-brown: #8B7355;    /* البني الأساسي */
  --light-brown: #D2B48C;      /* البني الفاتح */
  --dark-brown: #654321;       /* البني الغامق */
  --accent-gold: #D4AF37;      /* الذهبي (للتمييز) */
  --bg-cream: #F8F6F3;         /* خلفية كريمية */
  --text-primary: #2D2D2D;     /* نص أساسي */
  --text-secondary: #6B7280;   /* نص ثانوي */
}
```

### التدرجات اللونية
- **الأزرار الرئيسية**: `linear-gradient(135deg, #8B7355, #654321)`
- **النصوص المميزة**: `linear-gradient(135deg, #8B7355, #D4AF37)`
- **الخلفيات**: `linear-gradient(135deg, #F8F6F3, #F4EFE9)`

### الخطوط
- **Noto Kufi Arabic** - الخط العربي الأساسي
- دعم كامل للأوزان من 300 إلى 800
- تحسينات للقراءة: `text-rendering: optimizeLegibility`

- **Glass Effect**: خلفيات شفافة مع blur
