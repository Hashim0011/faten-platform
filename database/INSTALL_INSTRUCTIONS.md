# تعليمات التثبيت السريعة ⚡

## 🎯 ما تحتاج تسويه:

### 1️⃣ افتح Supabase Dashboard
```
https://app.supabase.com
```

### 2️⃣ اختر مشروعك

### 3️⃣ اذهب إلى SQL Editor
من القائمة الجانبية → **SQL Editor** → **New query**

### 4️⃣ نفذ الملفات بالترتيب:

#### أ. نظام الحظر (banned_users)
1. افتح ملف: `database/banned_users_table.sql`
2. انسخ **كل** المحتوى
3. الصقه في SQL Editor
4. اضغط **Run** أو `Ctrl+Enter`
5. انتظر رسالة النجاح ✅

#### ب. نظام اللايكات (likes)
1. افتح ملف: `database/UPDATE_likes_system.sql` ⚠️ **مهم: هذا وليس `likes_table.sql`**
2. انسخ **كل** المحتوى
3. الصقه في SQL Editor
4. اضغط **Run** أو `Ctrl+Enter`
5. انتظر رسالة النجاح ✅

---

## ✅ التحقق من النجاح:

### في Supabase Dashboard:

1. اذهب إلى **Table Editor**
2. تأكد من وجود:
   - ✅ جدول `banned_users`
   - ✅ جدول `likes`

3. اذهب إلى **Authentication** → **Policies**
4. تأكد من وجود Policies للجدولين

4. لو اشتغل = ✅ نجح!

## ❌ في حالة ظهور خطأ:

### خطأ: "relation does not exist"
**السبب:** الجدول مو موجود
**الحل:** تأكد إنك شغلت الـ SQL بشكل صحيح

### خطأ: "permission denied"
**السبب:** RLS Policy مو صحيحة
**الحل:** تأكد إنك مسجل دخول في الموقع

### خطأ: "duplicate key value"
**السبب:** نفس اللايك موجود (طبيعي!)
**الحل:** هذا يعني النظام يشتغل صح ✅
